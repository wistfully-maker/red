# 泸定行记样板

当前版为现场旁的悬浮手记：桌面右置72vw、最大1060px，四边28px；手机为76dvh高的底部抽屉，左右及底部8px，上方保留约24%的现场。背景仅轻遮，不加模糊。正文按面板的760px、520px与340px容器断点重排，固定页眉、切章导航与双行观察字幕，正文独立滚动。

## 入口与集成

- 直达 `#station/luding/journal`。模块自行监听 hash；主路由应把它识别为泸定研学模式。
- `assets/field-lessons.js` 在泸定研学区加入展开按钮。
- `assets/scene-studies.js` 的 `showStudy('luding')` 打开同一专题。其他站点保持原有手记。
- 关闭按钮、Escape与点击面板外留景区返回打开前的泸定路径；桥头、桥面、桥亭、地形与普通泸定入口各回原路径。原研学入口及直接打开 `/journal` 默认回 `#station/luding/study`。焦点回原触发器或对应入口。换站时自动关闭且不覆盖新地址。
- `openLudingJournal({returnHash})` 可显式指定返回路径；直接调用时记录当前路径，链接进入时从 `hashchange.oldURL` 捕获。同一页重开保留阅读位置、观察状态、答案与草稿。
- 显式关闭用 `location.replace(returnHash)` 替换 `/journal` 历史项，避免“关闭—后退又开”的循环。浏览器后退或换站已经改了hash时，关闭处理不再导航。
- 关闭后发送 `document` 事件 `luding-journal-closed`，`detail={returnHash,route:location.hash}`。主路由可根据 `hashchange.oldURL` 为journal、目标为原步行路径来保留相机和滑动位置。

本模块不改三维渲染，不接管相机，不请求音频。CSS 全部限定在 `#ludingJournal` 内。

## 视觉参考如何转化

参考网址为 [Capitolium](https://www.collabcapitolium.fr/)。从用户提供的约 34 秒录屏分析前段的图文对页、中段的明暗转换与后段错位图墙；样板中的图片来自单独登记的来源。

- 0—6秒：宽幅场景与窄文字并置，画面从场所逐渐带到人物。本页把这一节奏用于“大渡河实景 + 两段年代 + 行记员提问”，照片保留年份与图源。
- 9—15秒：大片浅底留白和较小图像形成停顿。本页使用四段短章与连续阅读进度，让判断题前有观察的空间。
- 18—31秒：深底错位图墙与跨尺度字形成视觉节拍。本页转为“后来实景 / 场景演绎”的错位对照；每张图保留类型、图注、作者、授权与证据边界。
- 色调沿用图集的淡纸、炭黑和朱红。深色章节用于阅读任务配合关系；色彩不表示史料可信等级。
- 面板短距离进入、桥板透明度切换、用户触发的平滑定位、切章下划线、关闭符号转动与照片编号轻放大共同构成反馈。照片标题、观察编号、结构构件支持鼠标悬浮、键盘聚焦与手机点按，联动当前标题和固定双行字幕。
- 字幕使用两个重叠的固定高度图层做淡入与轻抬升。照片细节说明也使用同一网格内的重叠图层，提前保留最高文本高度，切换不推动正文。没有自动翻页、无限漂浮和滚动劫持；页眉按钮与系统 `prefers-reduced-motion` 减弱时即时换字，保留完整说明。

## 学习内容与边界

1. **看现场**：通过9根底链、4根扶手链、桥台三个观察点理解结构。隐藏桥板只为看清构件，明确不是战斗时拆板范围复原，也不是精确工程测绘。
2. **找证据**：1706年建桥与1935年夺桥两条年代并置；用安顺场摆渡受限解释为何继续向泸定推进；把掩护、突击、铺板并列为配合任务，避免暗示三者严格先后且没有重叠。
3. **辨图像**：以2026年桥面近景与生成式场景设计图对照，练习只写画面直接支持的图注，不把后来照片或艺术演绎当成战斗现场证据。近景两个观察编号分别引导辨认相扣的椭圆铁环，以及横向木条与纵向长木板；它与封面2018年河岸全景内容不同。
4. **留行记**：按“我看见 / 材料告诉我 / 我仍想问”写三句话。与原研学共用 `long-march:field-note:luding`；可下载带资料链接的纯文本。无法写入 localStorage 时明确提示并保留本次页面草稿。

行记员是虚构的当代研学引导角色，不是1935年的见证人。她的引语是作者编写的提问。页面在肖像旁和图源说明中均标注此身份。

## 图像与替换

新收录照片为 Huangdan2060 于 Wikimedia Commons 发布的2018年泸定桥实景，作者标记 CC0 1.0：

https://commons.wikimedia.org/wiki/File:Luding_Bridge_over_the_Dadu_River,_in_Luding_County,_Sichuan,_China,_2018.jpg

照片原始色彩未调色，网页版面作裁切。原文件说明的描述、日期与结构化日期对具体月日存在差异，因此只显示“2018年”。下载的960px版本保存在 `assets/journal/luding-2018-cc0.jpg`，不依赖第三方图片服务器。

复用 `assets/scene-studies/luding.webp` 与 `assets/valley/recorder-portrait.webp`，它们均为项目既有生成式设计素材；没有新增拟档案照片。桥梁示意由SVG代码绘制。

图墙另收录 N509FZ 于2026-02-05从西向东拍摄的桥面实景，CC BY-SA 4.0：

https://commons.wikimedia.org/wiki/File:Luding_Bridge_from_the_west_(20260205115349).jpg

该照片按完整3:2比例显示，不裁切、不调色。观察编号通过网页按钮叠加，照片与其改编继续按CC BY-SA 4.0提供，页面同时显示署名、许可链接、原文件链接和修改说明。本地文件为 `assets/journal/luding-deck-2026-cc-by-sa.jpg`，完整素材授权记录见 `assets/journal/ATTRIBUTION.md`。

图源集中在 `assets/luding-journal-data.js` 的 `journalMedia`。替换图像时同时修改：

- `src`：本地资源路径；建议先下载已获授权原图，保留可离线访问。
- `alt`：说明画面实际可见的内容。
- `badge`、`kind`：纪实照片 / 艺术演绎 / 结构示意，以及照片年代。
- `caption`、`credit`、`license`、`source`：图注、作者、许可与原始文件页。
- `boundary`：该图能说明什么、不能说明什么。

如果替换了2026年桥面实景，还需同时调整该文件的 `imageQuestion`、照片观察编号坐标与说明，保持题干、答案与新图片一致。角色若换为真人摄影，须同步更新角色素材说明。
